# Contributing

This project implements security-sensitive infrastructure, and it is ALPHA software.
As such, it is critical that its signing paths and UX flows are battle-tested as 
much as possible. During this phase, the best way to help is to use the system and let 
us know if you see any problems, have suggestions for usability, new features, etc.

Due to the possibility of future rearchitecture during the ALPHA phase, and to minimize
complexity and risk during a period of potential change, external pull requests are 
respectfully declined. Once the software stabilizes in a later phase, this policy will 
be loosened. 

The code is published as open source for transparency, independent
audit, and reuse under the terms of the license. Forks are explicitly
permitted.

### Security Issues

If you believe you have identified a security vulnerability, please
email reports@aplane.io for private disclosure. Only open a public
issue for findings that have already been disclosed or are clearly
low-severity. Do not include private keys or sensitive material.

All reports are handled at the maintainer's discretion.
